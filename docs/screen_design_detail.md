# 画面詳細設計書

## 概要

本ドキュメントは「Jiro-Rimi Cup」の各画面の詳細設計を定義する。
全体概要（デザインコンセプト・画面一覧・画面遷移図・共通コンポーネント）は [画面設計書](./screen_design.md) を参照。

---

### SCR-001: ログイン画面

**パス**: `/login`

**概要**: Discord アカウントでログインするための画面

| No | 機能ID | 機能名 | 説明 | 対応バックログ |
|----|--------|--------|------|---------------|
| 1 | SCR-001-F01 | Discord ログインボタン | Discord OAuth 認証フローを開始する | 1.2.2 |
| 2 | SCR-001-F02 | ログイン状態リダイレクト | 既にログイン済みの場合、マイページまたは大会一覧にリダイレクト | 1.2.3 |

**画面要素**:
- アプリロゴ
- 「Discordでログイン」ボタン
- 利用規約リンク（任意）

**遷移先**:
- ログイン成功 → トップページ（`/`）
- トップページでプロフィール未完了と判定された場合 → マイページ（`/mypage`）に誘導
- プロフィール完了済みユーザーはトップページ（`/`）に着地

### SCR-002: マイページ（プロフィール設定）

**パス**: `/mypage`

**概要**: ユーザーのプロフィール情報を表示・編集する画面

| No | 機能ID | 機能名 | 説明 | 対応バックログ |
|----|--------|--------|------|---------------|
| 1 | SCR-002-F01 | アバター表示 | Discord アバター画像を表示（編集不可） | 1.3.1 |
| 2 | SCR-002-F02 | プレイヤー名入力 | ゲーム内プレイヤー名を入力・保存 | 1.3.2 |
| 3 | SCR-002-F03 | X ID 入力 | X (Twitter) ID を入力・保存（プロフィール完了の必須項目だが、初回登録時は未確定を許容） | 1.3.3 |
| 4 | SCR-002-F04 | 性別選択 | ボーイズ / ガールズ を選択 | 1.3.4 |
| 5 | SCR-002-F05 | ロール優先順位設定 | 5種のロールから3つを選び優先順位を設定 | 1.3.5 |
| 6 | SCR-002-F06 | 初回登録モード | 初回ログイン時は必須項目入力完了まで離脱不可 | 1.3.6 |

**画面モード**:

この画面は2つのモードを持つ。

| モード | 条件 | 特徴 |
|--------|------|------|
| **初回登録モード** | プロフィール未完了 | 必須項目入力を強制、他画面への遷移を制限 |
| **通常モード** | プロフィール完了済み | 自由に編集・遷移可能 |

**初回登録モードの仕様**:

- ウェルカムバナーを表示（「Welcome!」タイトル＋「プロフィールを完成させてください。」メッセージ）
- サブタイトルを「Complete your profile to join tournaments!」に変更
- サイドメニューのナビゲーションリンクを非活性化（My Page以外グレーアウト）
- ログアウトボタンも非活性化
- proxy（ミドルウェア）で `/mypage` と `/auth/callback` と `/api/profile` 以外へのアクセスを `/mypage` にリダイレクト
- 保存ボタンのラベルを「Complete Profile」に変更
- 全必須項目の入力完了・保存後、トップページ（`/`）へフルリロードでリダイレクト

**画面要素**:

**プロフィール情報セクション**:
| 項目 | 型 | 編集 | 必須 | 備考 |
|------|-----|------|------|------|
| アバター画像 | 画像 | 不可 | - | Discord アバターを表示（avatar_url） |
| プレイヤー名 | テキスト入力 | 可 | ○ | ゲーム内表示名 |
| X ID | テキスト入力 | 可 | ○ | @プレフィックス付きで入力 |
| 性別 | ラジオボタン | 可 | ○ | ボーイズ / ガールズ（トグル形式） |
| 第1希望ロール | セレクトボックス | 可 | ○ | 5種から選択 |
| 第2希望ロール | セレクトボックス | 可 | ○ | 5種から選択（第1と重複不可） |
| 第3希望ロール | セレクトボックス | 可 | ○ | 5種から選択（第1,2と重複不可） |

**ロール選択肢**:
- 上キャリー (top_carry)
- 下キャリー (bot_carry)
- 中央 (mid)
- タンク (tank)
- サポート (support)

**バリデーション**:
- X ID: 英数字とアンダースコアのみ、1-15文字
- ロール: 3つすべて選択必須、重複不可

**概要**: 参加可能な大会の一覧を表示する画面。各大会のイベント一覧（エントリーボタン含む）を直接表示する。旧大会詳細画面（SCR-004）の機能を統合。

| No | 機能ID | 機能名 | 説明 | 対応バックログ |
|----|--------|--------|------|---------------|
| 1 | SCR-003-F01 | 大会一覧表示 | 公開中の大会を一覧表示 | 1.5.1 |
| 2 | SCR-003-F02 | イベント一覧表示 | 各大会のイベント一覧を展開表示（日程・エントリー期限等） | 1.5.2 |
| 3 | SCR-003-F03 | エントリーボタン | 各イベントにエントリーする | 1.5.3 |
| 4 | SCR-003-F04 | エントリー期限チェック | 期限を過ぎたイベントはボタンを非活性化 | 1.5.4 |
| 5 | SCR-003-F05 | エントリーキャンセルボタン | エントリー済みのイベントをキャンセル | 1.5.4 |
| 6 | SCR-003-F06 | エントリー一覧への遷移 | イベントごとのエントリー一覧画面へ遷移 | 1.5.5 |
| 7 | SCR-003-F07 | チェックインボタン | エントリー済み予選にチェックインする | 2.2.1 |
| 8 | SCR-003-F08 | チェックイン時間帯チェック | チェックイン可能時間帯外ではボタンを非活性化 | 2.2.1 |
| 9 | SCR-003-F09 | 試合画面リンク | イベント進行中かつチェックイン済みの場合、参加者試合画面へのリンクを表示 | 2.4.1 |
| 10 | SCR-003-F10 | ランキングリンク | イベント開始（in_progress）以降、エントリー人数リンクをランキング画面へのリンクに切り替え | 2.5.1 |

**画面要素**:

**大会セクション**（大会ごとにセクションを表示）:
| 項目 | 説明 |
|------|------|
| 大会名 | tournaments.name（セクションヘッダー） |
| ステータス | 公開中 / 進行中 等（StatusBadge） |

**イベントカード**（各大会内にイベントを一覧表示）:
| 項目 | 説明 |
|------|------|
| イベント名 | events.name |
| 試合数 | events.matches_per_event |
| 参加上限 | events.max_participants（NULLは無制限） |
| 開催日 | scheduled_date |
| エントリー期間 | entry_start 〜 entry_end |
| チェックイン時間 | checkin_start 〜 checkin_end |
| エントリー人数 | 現在のエントリー数（リンク → イベントが scheduled: エントリー一覧 / イベントが in_progress 以降: ランキング画面） |
| 操作 | エントリー / キャンセル / 期限切れ |

**エントリーボタンの状態**:
| 条件 | ボタン状態 |
|------|----------|
| 招待制イベント | 「招待制」（非活性） |
| 未ログイン | 「ログインしてエントリー」（ログイン画面へ） |
| エントリー期限前 | 「エントリー開始前」（非活性） |
| 性別不一致 | 「参加対象外」（非活性） |
| エントリー期間中 & 未エントリー | 「エントリーする」（活性） |
| エントリー期間中 & エントリー済 | 「キャンセルする」（活性） |
| エントリー期限後 | 「エントリー締切」（非活性） |

**チェックインボタンの状態**:

エントリー・チェックインのボタンは常時表示し、条件未達時は非活性で状態を示す。

| 条件 | ボタン状態 |
|------|----------|
| 未エントリー | 「チェックイン」（非活性） |
| エントリー済 & チェックイン時間帯前 | 「チェックイン開始前」（非活性） |
| エントリー済 & チェックイン時間帯中 & 未チェックイン | 「チェックインする」（活性・プライマリ） |
| エントリー済 & チェックイン済み | 「チェックイン済み ✓」（非活性・成功色） |
| エントリー済 & チェックイン時間帯後 & 未チェックイン | 「チェックイン締切」（非活性） |

**試合画面リンクの状態**:

試合画面リンクは常時表示し、条件未達時は非活性で状態を示す。

| 条件 | 表示 |
|------|------|
| イベントが in_progress 以外 | 「試合画面を見る」（非活性） |
| イベントが in_progress & 未チェックイン | 「試合画面を見る」（非活性） |
| イベントが in_progress & チェックイン済み & マッチ未作成 | 「試合画面を見る」（非活性） |
| イベントが in_progress & チェックイン済み & マッチ作成済み | 「試合画面を見る」リンク（活性） |

**性別制限バッジ**:
| イベントの gender | バッジ表示 | スタイル |
|------------------|----------|----------|
| `boys` | Boys | 青（`bg-blue-100 text-blue-700`） |
| `girls` | Girls | ピンク（`bg-pink-100 text-pink-700`） |
| `null` | 表示なし | - |

**表示条件**:
- 未ログイン: すべての公開中大会を表示（エントリーボタンはログイン誘導）
- ログイン済み: すべての公開中大会を表示（エントリー・キャンセル操作可能）

| No | 機能ID | 機能名 | 説明 | 対応バックログ |

| 3 | SCR-007-F03 | イベント削除 | イベントを削除する | 1.4.3 |
| 4 | SCR-007-F04 | イベント名設定 | 各イベントのイベント名を設定 | 1.4.3 |

| 項目 | 型 | 必須 | デフォルト | 備考 |

| 項目 | 型 | 必須 | 備考 |

| チェックイン締切 | 日時入力 | ○ | checkin_end |
| 性別区分 | セレクトボックス | - | 制限なし / Boy / Girl。設定すると該当の性別のみエントリー可能 |
| ルール | テキストエリア | - | 任意 |
| 削除 | ボタン | - | イベントを削除 |
| ステータスバッジ | バッジ | - | 編集時・in_progress/completed時にヘッダーに表示（「進行中」/「終了」） |
| チェックイン管理 | テキストラベル付きボタン | - | 編集時のみ、ルール下のアクションエリアに表示。チェックイン管理画面へ遷移 |
| イベントを開始 | テキストラベル付きボタン | - | 編集時・scheduled時のみ、ルール下のアクションエリアに表示。押下で参加者選定モーダルを表示 |
| 試合管理 | テキストラベル付きボタン | - | 編集時・in_progress時のみ、ルール下のアクションエリアに表示。試合管理画面へ遷移 |

**バリデーション**:
- 大会名: 1-100文字
- イベント名: 1-100文字
- 試合数: 予選の場合は必須（1-10の整数）、ダブルエリミネーションの場合は入力不可
- 時系列制約: `entry_start < entry_end <= checkin_start < checkin_end`
- イベントは最低1つ必要

**操作ボタン**:

ボタンの表示は画面モード・大会ステータスに応じて切り替わる。

| モード | ステータス | 表示ボタン |
|--------|-----------|-----------|
| 作成 | - | キャンセル / 保存 |
| 編集 | draft | キャンセル / 公開 / 保存 |
| 編集 | open, in_progress | キャンセル / 非公開化 / 保存 |
| 編集 | completed | キャンセル / 保存 |

- 「保存」: 大会情報を保存（ステータスは変更しない）
- 「公開」: ステータスを open に変更して保存（draft 時のみ表示）
- 「非公開化」: ステータスを draft に変更して保存（open / in_progress 時のみ表示）
- 「キャンセル」: 変更を破棄して一覧に戻る

※ completed の大会はステータス変更不可（保存ボタンのみ）

**参加者選定モーダル（イベント開始時）**:

イベント開始ボタン押下で表示。チェックイン済みエントリーをクライアント側で取得して表示する。

**初期除外ルール**: 参加人数を10人単位（5v5 × 2チーム）に合わせるため、余剰人数分はチェックイン時刻が遅い参加者から初期除外候補として自動選出される。最終的な除外対象は運営者がモーダル上で変更できる。

| 項目 | 説明 |
|------|------|
| サマリー | 「チェックイン: X人 → 参加: Y人（Z人除外）」参加人数が10の倍数でないか10未満の場合は赤色警告 |
| 参加者リスト | チェックイン済みエントリー一覧（チェックイン時刻降順＝遅い順から表示）。チェックボックスで参加/除外をトグル |
| 自動除外 | デフォルトでチェックインが遅い順（リスト上部）からチェックイン済み人数 % 10 人を除外。運営者はチェックボックスで除外対象を自由に変更可能 |

**チーム編成ボード**（`team_assignment` 状態時のみ表示）:

**マッチ一覧**:

各マッチをカード形式で表示。

```
Match 1                    仮結果: Team A   確定結果: [Team A ▼]
┌─────────────────────┬─────────────────────┐
│ Team A              │ Team B              │
│ P1  [勝ち] ✓入力済 │ P6  [負け] ✓入力済 │
│ P2  [勝ち] ✓入力済 │ P7  [負け] ✓入力済 │
│ P3  [勝ち] ✓入力済 │ P8         ―未入力 │
│ P4  [勝ち] ✓入力済 │ P9  [負け] ✓入力済 │
│ P5         ―未入力 │ P10 [負け] ✓入力済 │
└─────────────────────┴─────────────────────┘
ロビー: 1234    入力状況: 8/10

Match 2                    ⚠ 不一致 (3:2)   確定結果: [― ▼]
┌─────────────────────┬─────────────────────┐
│ ...                                       │
└───────────────────────────────────────────┘
```

各マッチカードの表示内容:
| 項目 | 説明 |
|------|------|
| マッチ番号 | Match 1, Match 2, ... |
| Team A / Team B メンバー | プレイヤー名・投票内容（勝ち/負け）・入力状態（✓/―） |
| ロビー番号 | matches.lobby_number |
| 入力状況 | 投票済み人数 / 全参加者数 |
| 仮結果 | 多数決による算出結果（Team A / Team B / ⚠ 不一致） |
| 確定結果入力 | セレクトボックス（Team A / Team B）。運営者が直接指定 |

**マッチカードの状態（ラウンドステータス別）**:
| ラウンドステータス | 表示内容 |
|------------------|---------|
| in_progress | チーム構成 + 投票状況 + 仮結果 + 確定結果入力を表示 |
| confirmed | チーム構成 + 確定結果を表示。確定結果入力は非活性 |

**仮結果の算出ロジック**:

投票は自チーム視点で解釈する（`win` = 自チームが勝った、`lose` = 自チームが負けた）。相手チームの `lose` 投票も反映して仮結果を算出する。仮結果は参考情報であり、最終結果は管理者が確定する。

- Team A 勝利票 = (Team A の `win` 投票数) + (Team B の `lose` 投票数)
- Team B 勝利票 = (Team B の `win` 投票数) + (Team A の `lose` 投票数)

| 条件 | 表示 |
|------|------|
| Team A 勝利票 > Team B 勝利票 | 「Team A」（通常表示） |
| Team B 勝利票 > Team A 勝利票 | 「Team B」（通常表示） |
| 同数（1件以上の投票あり） | 「⚠ 不一致」（警告色でハイライト） |
| 全員未投票 | 「―」 |

**不一致マッチのハイライト**:
- マッチカード全体を警告色（イエロー）のボーダーで囲む
- 「⚠ 不一致」バッジを表示

**確定結果入力**:
- セレクトボックスで Team A / Team B を選択
- 仮結果が算出済みの場合はデフォルト値として設定
- 不一致の場合は未選択状態
- 全マッチに確定結果が設定されている場合のみ「結果確定」ボタンが有効化

**累計成績セクション**:

全参加者の現在の成績を表形式で表示。

| 項目 | 説明 |
|------|------|
| プレイヤー名 | profiles.player_name |
| 勝数 | confirmed マッチで所属チームが勝利した回数 |
| 敗数 | confirmed マッチで所属チームが敗北した回数 |
| 勝率 | 勝数 / (勝数 + 敗数) |

**備考**:
- イベントが in_progress 以外の場合はアクセス不可（リダイレクト）
- 結果確定後は当該ラウンドの確定結果入力セレクトボックスを非活性化
- イベント完了後は全操作ボタンを非表示

| 1 | SCR-012-F01 | イベントランキング表示 | イベント内の成績でランキングを表示（勝利数降順、同勝利数は同順位） | 2.5.1 |
| 2 | SCR-012-F02 | 対戦履歴表示 | 各ラウンドの対戦結果を表示 | 2.5.1 |
| 3 | SCR-012-F03 | 未ログイン閲覧許可 | 認証なしでも閲覧可能 | 2.5.1 |

**画面要素**:

**ヘッダー**:
- 大会名・イベント名の表示
- 大会一覧画面への戻るリンク

**ランキングセクション**:

イベント内の参加者の成績を表形式で表示。勝利数の降順でソート。同勝利数の参加者は同順位として表示。

| 項目 | 説明 |
|------|------|
| 順位 | 勝利数による順位（同勝利数は同順位） |
| アバター | profiles.avatar_url |
| プレイヤー名 | profiles.player_name |
| 勝数 | イベント内の勝利数 |
| 敗数 | イベント内の敗北数 |
| 勝率 | 勝数 / (勝数 + 敗数) |

```
ランキング
┌────┬──────────┬────┬────┬──────┐
│順位│プレイヤー │ 勝 │ 負 │ 勝率 │
├────┼──────────┼────┼────┼──────┤
│ 1  │ P1       │ 3  │ 0  │ 100% │
│ 2  │ P2       │ 2  │ 1  │  67% │
│ 2  │ P3       │ 2  │ 1  │  67% │
│ 4  │ P4       │ 1  │ 2  │  33% │
│ ...│          │    │    │      │
└────┴──────────┴────┴────┴──────┘
```

**対戦履歴セクション**:

各ラウンドの対戦結果を一覧表示。

```
ラウンド1: Team A（P1, P2, P3, P4, P5） vs Team B（P6, P7, P8, P9, P10） → Team A 勝利
ラウンド2: Team A（P1, P3, P6, P8, P10） vs Team B（P2, P4, P5, P7, P9） → Team B 勝利
...
```

各対戦結果の表示内容:
| 項目 | 説明 |
|------|------|
| ラウンド番号 | ラウンド 1, 2, ... |
| Team A メンバー | プレイヤー名のリスト |
| Team B メンバー | プレイヤー名のリスト |
| 結果 | 「Team A 勝利」/「Team B 勝利」 |

**備考**:
- confirmed マッチのみ表示対象（in_progress のマッチは非表示）
- 対戦履歴は全参加者の全マッチを表示（特定プレイヤーでのフィルタリングは将来対応）
